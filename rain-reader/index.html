Rain Reader

Singapore has no winter and no summer - but December brings about three times February's rain, and everyone, everywhere, checks the sky before leaving home. A weather station reads that story in two charts.

Your job: read the charts, work the station key, and place the four numbered tiles on the umbrella board.

  • 🐍Version BThe same task as Python code: work out what the program stores.

How to play

  1. Find a numbered badge on the charts and read the value at that point - with its unit.
  2. Look that value up in the station key to learn its tile number.
  3. Place that tile in the badge's slot on the umbrella board.
  4. Then answer one last question: which chart answers which kind of question?

Why this is computational thinking

  1. Decomposition: one big board becomes four small readings.
  2. Pattern recognition: the two charts look alike but measure different things - millimetres versus days.
  3. Abstraction: the key hides the arithmetic; only value and unit matter.
  4. Algorithm design: badge, read, look up, place - the same steps work for every slot, in any order.

Where the numbers come from

Both charts show real long-term averages recorded at Singapore's Changi climate station for 1991-2020, published by the Meteorological Service Singapore. Rainfall values are rounded to the nearest 10 mm so they can be read cleanly from the chart.

Version B shows the same numbers as Python dictionaries. Every value you trace in the code is a real reading from the station's climate table.
